# Рынок труда: ИИ-автоматизация и LLM-агенты — исследование hh.ru

**Август 2026 · hh.ru (Москва + удалёнка) · автор: [Антон Быстров](https://github.com/antonBy77)**

Пилотное исследование российского рынка труда в сегменте ИИ-автоматизации: что ищут работодатели, какие навыки просят, сколько платят — плюс полевой эксперимент **«как автоматизаторы сами автоматизируют найм»** (бот или человек отвечает на отклик первым?).

## Эксперимент «автоматизаторы ↔ автоматизация найма»

21 отклик за один день, каждый с персональным сопроводительным письмом. Фиксировали первый контакт работодателя.

- **Первые 2 ответа — оба бота:**
  - крупный банк топ-3 («AI Hub Finance»): отклик → автоинвайт на AI-интервью с **«ГигаРекрутер» (GigaChat)** через 0 минут;
  - продуктовая компания («AI Automation Engineer»): чат мгновенно подхватил **платформенный бот «ИИ-помощник hh»** и начал скрининг-анкету (вопросы — вплоть до «приведите пример класса и структуры данных»).
- 1 отклик из 21 просмотрен человеком за сутки, остальные без ответа.

**Вывод:** первый контакт на рынке автоматизирован даже там, где у работодателя нет собственного бота — платформа закрывает первый скрининг сама. Полный разбор — в [отчёте](report/AI_labor_market_report_2026-08-29.md).

## Методика (кратко)

1. Поиск hh.ru: «ИИ-агенты» (243 вакансии), «AI-автоматизация» (214), Москва + удалёнка, по 50 карточек.
2. Дедупликация → 93 уникальные → фильтр шума (продажи, SMM, маркетплейсы, контент, HR) → 30 инженерных.
3. Скоринг: агенты/LLM/автоматизация/удалёнка — плюс; маркетинг/контент/продажи — минус.
4. Глубокий разбор 19 топ-вакансий.
5. Полевой эксперимент: 21 персональный отклик + трекинг первого контакта (бот/человек, скорость).

Данные собраны через веб-интерфейс hh.ru.

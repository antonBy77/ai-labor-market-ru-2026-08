# Рынок труда: ИИ-автоматизация и LLM-агенты — исследование hh.ru

**Август 2026 · hh.ru (Москва + удалёнка) · автор: [Антон Быстров](https://github.com/antonBy77)**

Пилотное исследование российского рынка труда в сегменте ИИ-автоматизации: что ищут работодатели, какие навыки просят, сколько платят — плюс полевой эксперимент **«как автоматизаторы сами автоматизируют найм»** (бот или человек отвечает на отклик первым?).

## Ключевые цифры

| Метрика | Значение |
|---|---|
| Просканировано вакансий | **457** (2 поисковых запроса) |
| Уникальных после дедупликации | 93 |
| Инженерных после фильтра шума | **30** |
| Глубоких разборов (навыки/ЗП) | 19 |
| Доля удалёнки | **60%** |
| Медианная вилка (инженерные роли) | **150–250 тыс. ₽/мес** |
| Верх рынка | от 400 тыс. ₽ (Lead of IT & AI, удалённо) |

## Сентябрьское расширение (шаги 2–3, 2026-09)

**Шаг 2 — не-инженерные роли автоматизации** ([отчёт](report/step2_expansion_2026-09-03.md)): 15 запросов, вся Россия, срез 03.09. **790 постингов → 463 уникальных шаблона.** Аналитики — крупнейший кластер (156 шаблонов, медиана 150 тыс.), менеджеры автоматизации — самые дорогие (медиана 207,5 тыс.). «AI-тренер» оформился как массовая профессия (180 постингов до 133 тыс. у одного работодателя). Удалёнка 25%.

**Шаг 3 — задачи и отрасли** ([отчёт](report/step3_tasks_industries_2026-09-16.md)): свежий срез 03.09→16.09 — **341 новый постинг** по 12 запросам; разбор 80 полных описаний. Главные находки:

- самая частая и самая дорогая задача — **сквозные процессы/BPM** («взять процесс целиком»): 54% сэмпла, медиана 185 тыс. — против 112–140 тыс. у нишевых задач;
- **61% найма автоматизаторов — интеграторы и консалтинг внедрения**: они закрывают проекты в финансах, ритейле, промышленности и госсекторе сразу;
- потребность в **«AI-агентах» утроилась за 13 дней** (15 → 64 активных постинга);
- **ЭДО/документооборот — самая массовая «узкая» ниша** (100 постингов), появляются связки «ЭДО + ИИ» и «юрист-промпт-инженер».

## Эксперимент «автоматизаторы ↔ автоматизация найма»

21 отклик за один день, каждый с персональным сопроводительным письмом. Фиксировали первый контакт работодателя.

- **Первые 2 ответа — оба бота:**
  - крупный банк топ-3 («AI Hub Finance»): отклик → автоинвайт на AI-интервью с **«ГигаРекрутер» (GigaChat)** через 0 минут;
  - продуктовая компания («AI Automation Engineer»): чат мгновенно подхватил **платформенный бот «ИИ-помощник hh»** и начал скрининг-анкету (вопросы — вплоть до «приведите пример класса и структуры данных»).
- 1 отклик из 21 просмотрен человеком за сутки, остальные без ответа.

**Вывод:** первый контакт на рынке автоматизирован даже там, где у работодателя нет собственного бота — платформа закрывает первый скрининг сама. Полный разбор — в [отчёте](report/AI_labor_market_report_2026-08-29.md).

## Методика (кратко)

1. Поиск hh.ru: «ИИ-агенты» (243 вакансии), «AI-автоматизация» (214), Москва + удалёнка, по 50 карточек.
2. Дедупликация → 93 уникальные → фильтр шума (продажи, SMM, маркетплейсы, контент, HR) → 30 инженерных.
3. Скоринг: агенты/LLM/автоматизация/удалёнка — плюс; маркетинг/контент/продажи — минус.
4. Глубокий разбор 19 топ-вакансий.
5. Полевой эксперимент: 21 персональный отклик + трекинг первого контакта (бот/человек, скорость).
6. Шаг 2 (03.09): 15 запросов в названии вакансии, вся Россия; карточки → дедуп «шаблонов» по (название, ЗП).
7. Шаг 3 (16.09): свежий срез 12 запросов + выборочный разбор полных описаний (80 вакансий) с классификацией задач и отраслей.

Данные собраны через веб-интерфейс hh.ru.

## Правовой статус данных

- Все поля в `data/` — **фактические сведения** о публично размещённых вакансиях hh.ru (должность, зарплата, опыт, формат, ключевые навыки), собранные через обычный веб-интерфейс в исследовательских целях; суммарный объём выборки — свыше 1300 записей (шаги 1–3).
- Авторские тексты вакансий не воспроизводятся; каждая детальная карточка содержит ссылку на первоисточник (`https://hh.ru/vacancy/<id>`).
- Имена работодателей упоминаются по необходимости (фактическая идентификация вакансий), без оценочных суждений.
- Персональные данные физических лиц в датасете отсутствуют (проверено автоматически).
- Данные носят некоммерческий исследовательский характер и не заменяют собой сервис hh.ru. По обоснованному запросу правообладателя соответствующие записи будут удалены — создайте issue или напишите на antonbustrov@gmail.com.

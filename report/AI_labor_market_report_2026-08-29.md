# Рынок труда: ИИ-автоматизация и LLM-агенты — отчёт исследования

**Дата:** 29.08.2026 · **Источник:** hh.ru (Москва + удалёнка) · **Автор:** Антон Быстров ([@antonBy77](https://github.com/antonBy77))

Исследование российского рынка труда в сегменте ИИ-автоматизации: структура спроса, топ-навыки, зарплаты — и полевой эксперимент «как автоматизаторы сами автоматизируют найм».

Контекст автора: AI-native инженер, основатель алгоритмического фонда QuantumStocks (19 LLM-агентов в проде, algo trading). Профиль исследования — инженерные роли в ИИ-автоматизации; из выборки исключены видео, маркетинг, контент-конвейеры.

---

## 1. Методика

1. Поиск hh.ru по запросам: «ИИ-агенты» (243 вакансии), «AI-автоматизация» (214 вакансий), area=1 (Москва + удалёнка), по 50 карточек.
2. Парсинг карточек → 93 уникальные вакансии → фильтр шума (продажи, SMM, маркетплейсы, контент, HR) → **30 инженерных вакансий**.
3. Скоринг под профиль: агенты/LLM/автоматизация/удалёнка — плюс; маркетинг/контент/продажи — минус.
4. Глубокий разбор 19 топ-вакансий (страницы вакансий: работодатель, зарплата, ключевые навыки) → `data/details/`.
5. Полевой эксперимент: 21 отклик с персональными сопроводительными письмами; фиксация первого контакта работодателя (бот/человек, скорость, содержание) — см. раздел 6.

Данные собраны через веб-интерфейс hh.ru (публичный API для автоматизированного доступа недоступен), сырые выгрузки — в `data/`.

## 3. Топ-навыки индустрии (корпус: 19 глубоких разборов)

**Ядро (встречаются чаще всего):**
- **Python** — де-факто обязателен
- **LLM / AI-агенты** — само ядро запроса
- **RAG** (Retrieval-Augmented Generation)
- **Prompt Engineering**
- **API-интеграции** (OpenAI, Claude, Gemini, DeepSeek)
- **Git** — базовая гигиена
- **Docker** — контейнеризация

**Фреймворки агентов (называют по именам):** LangChain, **LangGraph**, CrewAI, AutoGen, MCP-инструменты. Собственный оркестратор в резюме фильтры HR проходит хуже, чем общепринятые фреймворки, — для прохождения фильтров нужны 1–2 публичных проекта на стандартном стеке.

**No-code/low-code автоматизация:** **n8n**, Dify, Битрикс24 — отдельный большой кластер вакансий «интегратор/автоматизатор»; порог входа низкий, освоение за 2–3 дня.

**Инфраструктура поиска:** Vector DB — Qdrant, Milvus, Pinecone; семантический поиск.

**MLOps/LLMOps:** MLflow, Weights & Biases, LLMOps, fine-tuning — для senior-ролей.

**Backend-стек рядом с агентами:** FastAPI, asyncio, PostgreSQL, RabbitMQ, SQLAlchemy.

## 6. Полевой эксперимент «автоматизаторы ↔ автоматизация найма»

**Гипотеза:** компании, которые сами продают или внедряют автоматизацию, отвечают на отклики автоматизированно.

**Схема:** 21 отклик за один день (3 quant-роли + 18 ролей ИИ-автоматизации), каждый с персональным сопроводительным письмом (вхождение под формулировку вакансии + их ключевые навыки + конкретное предложение «соберу прототип за 2 дня, публичный GitHub»). После отправки фиксировался первый контакт работодателя: бот/человек, скорость, содержание. Откликнувшимся компаниям названия в публичной версии не раскрываются (кроме случая, когда это уже публичный факт).

**Результаты первых 24 часов:**

| Сигнал | Кол-во | Детали |
|---|---|---|
| Первый ответ — **бот** | **2** | см. ниже |
| Первый ответ — человек | 0 | — |
| Отклик просмотрен человеком | 1 из 21 | без ответа |
| Без сигнала | 18 | мониторинг продолжается |

Оба ответивших:
1. **Крупный банк топ-3** (вакансия «AI Hub Finance, направление ИИ-агенты»): отклик в 19:37 → в 19:37 автоинвайт на первичное AI-интервью от **«ГигаРекрутер» (GigaChat)** — бот-рекрутер ведёт интервью в Max/Telegram.
2. **Продуктовая компания** (вакансия «AI Automation Engineer»): к чату через 0 минут подключился **платформенный бот «ИИ-помощник hh»** и начал скрининг-анкету: «есть ли высшее образование в ИТ?» → «приведите пример класса и структуры данных, которые вы реализовали в проекте?». Бот принимает развёрнутые текстовые ответы и обещает «ускорить решение компании».

**Промежуточные выводы:**
- **Первый контакт автоматизирован даже там, где у работодателя нет собственного бота** — платформа найма закрывает первый скрининг сама. «Попасть на живого человека» — отдельная задача, решаемая качеством ответов боту.
- hh.ru у ~60% вакансий делает «мгновенный отклик» **без сопроводительного письма** — письмо приходится доставлять сообщением в чат отдельно.
- Боту можно и нужно отвечать содержательно: развёрнутые технические ответы (пример класса + структуры данных) проходят в анкету и пересылаются работодателю.
- Ставка на персональные письма с проверяемыми артефактами (публичный GitHub, live-трек) — способ дожить до человеческого этапа сквозь боты.
